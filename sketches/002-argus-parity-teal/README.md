# Variant 002 — full Argus parity (teal)

## Design stance
Same structure as 001, but Charon drops the gold and adopts Argus' teal/cyan identity outright, so the
two plugins read as one suite when they sit side by side on the same toolbar.

## Key choices
- **Layout** — identical to 001.
- **Colour** — accent `#29c7bd` (Argus teal) with the soft tint `#80ebe0`, teal→blue header gradient,
  teal selection bar/wash, teal toggles and buttons, teal tile stripes. The mark's iris goes blue so the
  eye still has contrast against the teal ring.
- **Semantics remapped** — teal stops meaning "good" and becomes "this is the brand"; mint stays good,
  amber stays "something is waiting for you", rose stays a problem, cyan stays informational.
- **Typography, components, interaction** — identical to 001.

## Trade-offs
- Strong at: visual coherence across the fleet's plugins; Charon and Argus look deliberately related.
- Weak at: Charon loses the Greek-pantheon identity it shares with Daedalus (dark + gold), so the family
  resemblance moves from Daedalus to Argus.

## Best for
- A future where the companion plugins are presented as one product line.

## Note
This variant differs from 001 **only** in accent identity — that was the point of building it. If neither
"gold" nor "teal" is the answer, a hybrid (gold chrome, teal informational accents) is one token away.
